# Site OziRP — version avec catalogue de commandes

Cette version contient :

- `index.html` : nouvelle page d’accueil OziRP
- `commandes.html` : catalogue des 43 commandes du bot avec une courte description
- `politique-confidentialite.html` : politique de confidentialité
- `cgu.html` : Conditions Générales d’Utilisation
- `styles.css` : design du site
- `script.js` : recherche locale dans la liste des commandes

## Mise à jour sur GitHub Pages

Dans ton dépôt `ozirp-site`, remplace les fichiers existants par ceux de ce dossier et ajoute :
- `commandes.html`
- `script.js`

Puis valide avec **Commit changes**.

GitHub Pages republiera automatiquement le site.

Le champ de recherche fonctionne uniquement dans le navigateur et n’envoie aucune donnée vers un serveur externe.
