Conditions Générales d’Utilisation de OziRP

Version 1.0 — 15 août 2026

Les présentes Conditions Générales d’Utilisation, ci-après « CGU », définissent les règles applicables à l’utilisation du bot Discord OziRP.

L’utilisation de OziRP implique l’acceptation des présentes CGU ainsi que le respect des règles de Discord et du serveur Discord sur lequel le bot est utilisé.

1. Présentation de OziRP

OziRP est un bot Discord proposant différentes fonctionnalités destinées principalement au roleplay.

Il peut notamment permettre :

  • la création de personnages fictifs ;
  • la création de documents RP ;
  • la gestion de comptes bancaires fictifs ;
  • la gestion de métiers et services RP ;
  • la gestion de véhicules ;
  • la gestion de permis ;
  • la gestion de cartes professionnelles ;
  • la gestion de factures et contraventions RP ;
  • la liaison avec un compte Roblox ;
  • la gestion de transports ;
  • la gestion de sanctions ;
  • et différentes fonctionnalités nécessaires au fonctionnement d’un serveur roleplay.

2. Acceptation des CGU

L’utilisation de OziRP signifie que l’utilisateur accepte les présentes CGU.

Lorsqu’une confirmation est proposée pendant l’onboarding ou lors de l’utilisation d’une fonctionnalité, l’utilisateur doit avoir pris connaissance des informations présentées avant de poursuivre.

Si l’utilisateur refuse les présentes conditions, il doit cesser d’utiliser OziRP.

3. Conditions d’accès

Pour utiliser OziRP, l’utilisateur doit :

  • disposer d’un compte Discord autorisé à utiliser la plateforme ;
  • respecter les Conditions d’utilisation et règles de Discord ;
  • respecter le règlement du serveur sur lequel OziRP est utilisé ;
  • utiliser les fonctionnalités du bot uniquement dans le cadre prévu.

Certaines fonctionnalités peuvent être limitées à certains rôles, métiers, services ou membres du staff.

4. Nature fictive du service

OziRP est un outil de roleplay.

Les éléments créés ou gérés avec OziRP sont fictifs, notamment :

  • identités ;
  • cartes d’identité ;
  • permis ;
  • cartes grises ;
  • cartes professionnelles ;
  • permis de port d’arme ;
  • certificats ;
  • comptes bancaires ;
  • cartes bancaires ;
  • codes PIN ;
  • crédits ;
  • factures ;
  • contraventions ;
  • assurances ;
  • fiches de paie ;
  • professions ;
  • grades ;
  • documents administratifs.

Ils n’ont aucune valeur officielle, administrative, bancaire ou juridique.

5. Interdiction d’utiliser les documents comme de vrais documents

Les documents générés avec OziRP sont exclusivement destinés à être utilisés dans le cadre du roleplay.

Il est notamment interdit :

  • de présenter un document OziRP comme un véritable document officiel ;
  • de l’utiliser pour tromper une personne ou une organisation ;
  • de l’utiliser pour usurper une identité réelle ;
  • de l’utiliser dans une véritable démarche administrative ;
  • de l’utiliser comme justificatif réel ;
  • de modifier un document afin de masquer son caractère fictif ;
  • de supprimer volontairement une mention indiquant qu’il s’agit d’un document RP afin de tromper un tiers.

OziRP n’est affilié, soutenu ou approuvé par aucune administration publique ou institution réelle, sauf indication expresse contraire.

Les éventuelles ressemblances avec des documents réels servent uniquement à renforcer l’immersion du roleplay.

6. Données exclusivement fictives dans les fonctionnalités RP

L’utilisateur s’engage à ne pas utiliser de véritables données sensibles dans les formulaires RP de OziRP.

Il est notamment interdit de renseigner :

  • un vrai numéro de carte bancaire ;
  • un vrai code PIN bancaire ;
  • un véritable IBAN ;
  • un véritable mot de passe ;
  • un token Discord ;
  • un véritable numéro de sécurité sociale ;
  • un véritable numéro de pièce d’identité ;
  • des données médicales réelles ;
  • des identifiants confidentiels ;
  • ou toute autre information sensible qui n’est pas nécessaire au fonctionnement du service.

Les informations demandées pour les personnages et documents doivent être fictives et adaptées au roleplay.

7. Banque et économie RP

Toutes les sommes d’argent affichées ou gérées par OziRP sont virtuelles.

OziRP :

  • n’est pas un établissement bancaire ;
  • ne fournit aucun service financier réel ;
  • ne conserve aucun argent réel ;
  • ne permet aucun paiement bancaire réel ;
  • ne fournit aucun crédit réel ;
  • ne fournit aucun service d’assurance réel.

Les cartes bancaires, comptes, codes PIN et prêts présents dans OziRP sont uniquement des mécanismes de jeu.

L’utilisateur ne doit jamais réutiliser un véritable code bancaire ou une véritable information financière dans OziRP.

8. Liaison Roblox

Certaines fonctionnalités peuvent permettre de lier un compte Roblox à un compte Discord.

L’utilisateur doit uniquement lier un compte Roblox qu’il est autorisé à utiliser.

OziRP peut utiliser certaines informations publiques du compte Roblox afin notamment d’afficher :

  • le nom d’utilisateur ;
  • l’identifiant ;
  • le nom d’affichage ;
  • l’avatar du personnage.

OziRP ne demande pas et ne doit jamais demander le mot de passe Roblox.

9. Utilisation acceptable

Il est interdit d’utiliser OziRP pour :

  • enfreindre la loi ;
  • contourner les règles de Discord ;
  • harceler ou menacer une personne ;
  • usurper une identité réelle ;
  • effectuer une fraude ;
  • récupérer des informations personnelles sans autorisation ;
  • envoyer du spam ;
  • exploiter volontairement une faille ;
  • perturber le fonctionnement du bot ;
  • accéder aux données auxquelles l’utilisateur n’est pas autorisé ;
  • contourner les restrictions de rôles ou de permissions ;
  • utiliser les fonctionnalités RP à des fins réelles trompeuses ou frauduleuses.

10. Sécurité

L’utilisateur ne doit jamais communiquer :

  • son mot de passe Discord ;
  • son token Discord ;
  • son mot de passe Roblox ;
  • un véritable mot de passe personnel ;
  • ses informations bancaires réelles ;

à OziRP ou à une personne prétendant représenter OziRP.

L’équipe OziRP ne demandera jamais le token Discord ou le mot de passe d’un utilisateur.

Toute tentative d’accès non autorisé au bot, à son hébergement, à sa base de données ou à ses systèmes peut entraîner une suspension immédiate.

11. Disponibilité du service

L’équipe OziRP tente de maintenir le bot disponible dans des conditions normales.

Cependant, le service peut être temporairement indisponible notamment en cas de :

  • maintenance ;
  • mise à jour ;
  • panne ;
  • problème Discord ;
  • problème Roblox ;
  • problème d’hébergement ;
  • incident de sécurité ;
  • surcharge ;
  • modification technique.

La disponibilité permanente du service n’est pas garantie.

12. Modifications et mises à jour

OziRP peut évoluer à tout moment.

Des fonctionnalités peuvent être :

  • ajoutées ;
  • modifiées ;
  • remplacées ;
  • suspendues ;
  • ou supprimées.

Les présentes CGU peuvent également être modifiées pour tenir compte de l’évolution du service ou de la réglementation.

13. Suspension ou restriction d’accès

L’accès à certaines fonctionnalités de OziRP peut être temporairement ou définitivement restreint en cas notamment de :

  • violation des présentes CGU ;
  • violation des règles Discord ;
  • tentative de fraude ;
  • utilisation abusive ;
  • exploitation d’une faille ;
  • tentative d’accès non autorisé ;
  • menace pour la sécurité du bot ou de ses utilisateurs.

Une mesure peut concerner une fonctionnalité particulière ou l’ensemble du service.

14. Responsabilité de l’utilisateur

L’utilisateur est responsable des informations qu’il saisit et des actions qu’il effectue avec OziRP.

Il doit vérifier que les informations utilisées dans le roleplay ne correspondent pas inutilement aux véritables informations personnelles d’une personne.

L’utilisateur est également responsable de l’utilisation qu’il fait des images et documents générés par OziRP.

15. Propriété intellectuelle

Les éléments propres à OziRP, notamment son nom, son organisation, son code et ses créations originales, restent la propriété de leurs détenteurs respectifs.

Les marques, noms, logos et éléments appartenant à Discord, Roblox ou à d’autres tiers restent la propriété de leurs détenteurs respectifs.

L’utilisation de OziRP n’accorde aucun droit de propriété sur ces éléments.

16. Données personnelles

L’utilisation des données personnelles par OziRP est décrite dans la Politique de confidentialité de OziRP.

L’utilisateur doit pouvoir consulter cette politique avant ou pendant l’utilisation du service.

Il peut demander l’accès, la rectification ou la suppression de ses données en utilisant les moyens indiqués dans cette politique.

17. Support et signalement

Un utilisateur peut signaler :

  • un dysfonctionnement ;
  • une faille de sécurité ;
  • une utilisation abusive ;
  • une violation des règles ;
  • un problème lié à ses données ;

au moyen du système officiel de support ou de tickets de OziRP ou par email à :

ozi.rp26@gmail.com

Les signalements sont examinés par les personnes autorisées.

18. Services tiers

OziRP dépend notamment de services fournis par des tiers tels que :

  • Discord ;
  • Roblox ;
  • Oracle Cloud Infrastructure.

Ces services possèdent leurs propres conditions d’utilisation et politiques de confidentialité.

Une interruption ou modification de l’un de ces services peut affecter certaines fonctionnalités de OziRP.

19. Fin d’utilisation

L’utilisateur peut cesser d’utiliser OziRP à tout moment.

Il peut également demander la suppression de ses données conformément à la Politique de confidentialité.

Lorsqu’une donnée n’est plus nécessaire au fonctionnement du service ou doit être supprimée conformément aux règles applicables, elle est supprimée ou anonymisée.
