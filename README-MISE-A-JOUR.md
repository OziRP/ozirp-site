# OziRP — Mise à jour TikTok & Ko-fi (octobre 2026)

Cette mise à jour enrichit le site OziRP existant. Elle ne touche ni aux CGU, ni à la politique de confidentialité, ni aux images du dossier `assets/`.

## Modifications

- `index.html` : une grande section « Vivez Lunel RP même hors du jeu », cartes TikTok et Ko-fi avec boutons.
- `lunel-rp.html` : même section communautaire sur la page du serveur.
- `commandes.html` : ajout des deux liens dans le pied de page.
- `styles.css` : styles adaptatifs pour les deux nouvelles cartes.
- `script.js` : inchangé, inclus pour constituer un paquet complet.

Liens officiels fournis :
- TikTok : https://www.tiktok.com/@lunel_rp
- Ko-fi : https://ko-fi.com/lunelrp

## Publication sur GitHub Pages

1. Ouvrir https://github.com/OziRP/ozirp-site/upload/main
2. Décompresser ce ZIP sur votre ordinateur.
3. Déposer les fichiers **HTML, CSS et JS à la racine** de la branche `main`, c.-à-d. au même niveau que le `index.html` actuel (ne pas transférer le ZIP ni créer un sous-dossier).
4. Valider via `Commit changes`.
5. Vérifier : https://ozirp.github.io/ozirp-site/

Ne pas supprimer les fichiers juridiques `cgu.html` et `politique-confidentialite.html` et le dossier `assets/` présents sur GitHub. Le site a besoin du logo présent dans `assets/` pour l'affichage optimal.

Soutien Ko-fi : participation facultative, distincte de la monnaie RP.
